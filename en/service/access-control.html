Hong Kong access control system installation and maintenance

101 Lock provides Hong Kong access control system installation and access control system maintenance. The access control project is not just about installing an electric lock; the door type, daily flow of people, power outage status, fire escape, backup power supply, card access control or password access control permissions, and future management methods all need to be planned.

Reservation access control system evaluationSend door photo

Main components of access control system

A suitable access control system solution needs to integrate access control electric locks, identity verification, controllers and power supply, and select equipment according to on-site door types and usage methods.

Access control electric lock and door body

Electromagnetic locks, cathode locks, anode locks or electric bolt locks must be matched with wooden doors, glass doors, aluminum doors and door frame structures.

Card and password access control

Card access control, password access control, fingerprint or mobile phone vouchers have different management costs, security levels and separation methods.

Access controller and power supply

Includes access controller, door switch, fire alarm interface, backup battery, door sensor and schedule setting.

The following photos show the password access control keypad, access control panel, power supply and wiring inspection. Before repairing the access control system, you need to check the controller, power supply, circuits and access control electric locks to determine the location of the fault.

Planning process

  1. Onsite use:Confirm the number of users, opening hours, visitor arrangements and managers.
  2. Doors and escapes:Check door type, door opening direction, door closer, fire escape requirements and power outage status.
  3. System solution:Determine single door or multiple doors, independent or networked, and permission record requirements.
  4. Installation test:Complete wiring, fixing, alignment, power supply testing and administrator handover.
Safety points:When it comes to fire escapes, fire doors or public areas of the building, confirmation must be obtained from the owner, management office and relevant professionals first, and it cannot be handled just like ordinary door locks.

Common fault inspection

  • There is a response when tapping the card but the door lock does not release: Check the power supply, relay, lock body and door pressure.
  • The door often does not close properly: Check the alignment of the door closer, door hinge, deadbolt and door frame.
  • Cannot be used after a power outage: Confirm the power on/off settings and the backup battery status.
  • Individual cards are invalid: check the permissions, validity period, card type and controller records.

Frequently asked questions about access control systems

Is it necessary to visit the door before quoting the access control system?

Photos can make a preliminary judgment, but the wiring, power supply, door frames and fire interfaces of the access control system usually require on-site inspection.

Can the access control system retain the existing card?

It depends on the card format, frequency, controller compatibility and existing system management rights, and cannot be judged by appearance alone.

Is the access control system equal to the attendance system?

Not necessarily. The access control system controls access; the time and attendance system involves employee records, reports and privacy management, and functions and data responsibilities must be defined first.

Organize on-site information before installing the access control system

Provide the front and back of the door, door frame, nearby power supply, existing access control controller and expected number of users to facilitate a preliminary assessment of access control system installation or repair options.
