三开锁・三段锁

结构・用法・改款・安装尺寸 | 香港旧式公屋／不锈钢门专用

名称由来 三段结构

三开锁慨名称源自其内部结构分为三段：一段斜利行程 + 两段方闩。三段独立运作，提供「自动上锁 + 手动加强」慨双重安全保障。

常见安装位置

香港旧式公屋木门、不锈钢门、铁闸、大门等。因其坚固可靠，至今仍广泛使用。

斜利＋双方闩 自动上锁

斜利（斜舌）负责关门即自动锁上；两段方闩可分别用锁匙或室内扭手伸出，提供额外防盗强度。三段各自独立，互不干扰。

安装尺寸

锁中：60mm （锁胆中心至锁体边缘距离）
锁窿：32mm （门侧边开孔直径）
适用大部份标准旧式门预留孔位。

室外用法 (屋外操作)

出门锁门
  • 1. 关上门 → 斜利自动锁上 (第一段)
  • 2. 如需更加安全，用锁匙顺时针拧两下 → 伸出两段方闩 (第二、三段)
    • ※ 拧一下只会伸出第一段方闩，拧两下完全锁定。
入屋开门
  • 方法一 (完全解锁)：锁匙拧两下 → 先后收回两段方闩；再拧第三下 → 收回斜利，开门。
  • 方法二 (快速开门)：直接拧一下 → 只收回斜利（假设方闩未伸出），即可推门。
  • 实际情况视乎方闩有冇锁上，若只靠斜利自动锁，拧一下就可开门。

室内用法 (屋内操作)

停留 / 普通锁门
  • 关上门 → 斜利自动锁上 (同室外一样)
  • 如需更加安全，将室内扭手拧两下 → 伸出两段方闩，完全锁死。
  • ※ 扭手只可控制方闩，斜利保持自动状态。
室内离开
  • 先将室内扭手拧两下 → 收回两段方闩
  • 再拉手一下 → 收回斜利，同时开门
  • 整个过程快速流畅，唔需要用锁匙。
改款类型室内设计优点 / 适用场景
标准三开锁室内扭手 (旋钮) 控制方闩简单直接，适合木门、屋内快速锁门。
改款：室内锁胆室内扭手改成锁胆，需用锁匙控制方闩主要好处： 如安装喺铁闸，可避免贼人用衣架／铁枝从闸缝勾开方闩，大大提高防盗能力。

室外入屋流程图解

锁定状态开锁动作解锁结果
只有斜利自动锁上 (方闩未锁)锁匙拧一下收回斜利，直接开门
斜利 + 一段方闩已锁锁匙拧两下 → 收回方闩，再拧第三下收回斜利完全解锁，可开门
斜利 + 两段方闩全锁锁匙拧两下收回两段方闩，再拧一下收回斜利 (共三下)完整开门流程

室内扭手使用对比

  • 停留 / 一般上锁：关门自动锁斜利；拧扭手两下 → 方闩全伸出（加强防盗）。
  • 从室内离开：拧扭手两下收回方闩 → 拉手一下收回斜利 → 开门。
  • 紧急情况：如果只有斜利锁上，直接拉手即可开门，无需拧扭手。
安全提醒： 若铁闸使用标准三开锁（室内扭手），贼人可能用铁丝从闸缝勾动扭手从而开锁。建议铁闸改用「改款室内锁胆」三开锁，必须用锁匙先开到，杜绝衣架解锁风险。

安装尺寸及注意事项

标准尺寸：

  • 锁中 (Backset)：60mm
  • 锁窿直径：32mm
  • 适用门厚：35mm – 50mm (常见木门/不锈钢门)

更换提示：

  • 更换三开锁前请先确认锁中距离是否60mm，否则需要重新开孔。
  • 如果原有锁体系旧式「葫芦胆」，三开锁多数可兼容。
  • 建议搵专业开锁师傅安装，确保斜利及方闩对准门框。
常见问题解答
三开锁关门会自动锁吗？会，斜利（斜舌）具有自动弹出功能，关门即锁。方闩需要手动用锁匙或室内扭手锁上。
点解室外有时拧一下锁匙就开到门？因为你之前只靠斜利自动锁，冇锁上方闩。只需拧一下收回斜利即可开门。
铁闰用三开锁点样防「衣架开锁」？选用「改款室内锁胆」版本，室内要用锁匙先开到，无法从外面用铁丝勾动。
三开锁同一般大门锁有咩分别？一般大门锁通常只有斜利＋一段方闩；三开锁拥有两段方闩，防盗力更强且结构清晰。
